Implementation Plan

Phased roadmap for capacity and scheduling optimization — Q3 2026 to Q2 2027

Phased roadmap
PHASE A — Q3 2026 · Immediate Wins · $0 CapEx
Define WIP Buffer Minimums
Enforce 60-unit minimum at all 3 buffer points. Prevents downstream stoppages from batch failures.
Cost: $0 · Owner: Ops Manager
Add 5th Annealing Oven Cycle
Schedule 5th oven cycle to match Phase 1.1 vessel output. Eliminates 60 aerogel/week output loss.
Cost: $0 · Owner: Ops Manager
Deploy Kanban Visual Boards + SPC Charts
Install Kanban at all 3 WIP buffer points. Launch statistical process control at QC grading gates.
Cost: ~$700 · Owner: Ops Manager / QC Lead
PHASE B — Q4 2026 · Phase 1.1 Go-Live · $50K–$150K
Commission Cassette Molding System
Upgrade from manual to semi-automated cassette molding. Reduces cycle time from 10.9 to ~10 min/gel. Already in design phase.
Cost: $50K–$150K · Owner: Engineering
Launch MTO/MTS Hybrid Strategy
Pre-build standard aerogel sizes (Full Lite + Patio) into MTS buffer. Convert IGU assembly to MTO. Cuts effective customer lead time from 74h to <24h for repeat orders.
Cost: $0 · Owner: Ops Manager
Cross-Train Staff + Preventive Maintenance Schedule
Train molding staff on vessel loading for flex coverage. Define PM windows for vessel and oven — protects at 89% utilization.
Cost: ~$3K · Owner: HR / Engineering
PHASE C — Q1–Q2 2027 · Strategic Investment · $300K–$1M+
Procure Second 60" CPD Vessel
Removes the binding constraint — enables 500+ aerogels/week. Issue RFQ in Q1, procure and install in Q1–Q2, commission Q2.
Cost: $300K–$1M+ · Owner: CEO / Engineering
OEE System + Phase 2 Capacity Evaluation
Deploy real-time OEE tracking on vessel, oven and composite line. Evaluate Phase 2 gap vs. 5,600 sqft/week ARPA-E target.
Cost: $10K–$30K · Owner: IT / CEO
