AnalytIQ

Live at myanalytiq.org · source

Analytics professors can't assign much code, because grading it means either reading every submission by hand or comparing it to a reference answer as text — and text comparison doesn't measure correctness. AnalytIQ takes a professor's own chapter, generates exercises with executable test cases from it, and scores submissions by running the code and checking the actual output. No string-similarity comparison anywhere in the grading path. It plugs into an institution's existing LMS over LTI 1.3, so students never create an account and grades flow straight back to the gradebook.
